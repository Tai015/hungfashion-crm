\section{Lệnh thường dùng}
Từ thư mục \texttt{\detokenize{store-admin}}:
\begin{verbatim}
npm ci
npm run dev:local
npm run db:migrate --workspace server
npm run seed
npm run build
\end{verbatim}
Lệnh backup/restore và quy trình kiểm tra được trình bày tại Mục~\ref{sec:backup-restore}. Restore có thể ghi đè dữ liệu database đích; chỉ thực hiện trên database kiểm thử đã xác nhận.

\section{Việc cần làm trước khi nộp}
\begin{itemize}
\item Bổ sung tên nhóm, lớp, giảng viên, thành viên/MSSV, phân công, phần trăm đóng góp và tự đánh giá điểm dựa trên xác nhận của nhóm.
\item Xác nhận tên pháp lý, địa chỉ, hoạt động, mô hình và quy mô nhân sự của doanh nghiệp; không lấy suy luận từ seed làm thông tin thực.
\item Thu thập khảo sát HTTT thật, điền số phiếu/tỷ lệ/kết luận; không dùng dữ liệu demo thay cho khảo sát.
\item Chụp ảnh giao diện/triển khai thực tế và thay các placeholder [CHÈN ẢNH]; che mật khẩu, token, thông tin cá nhân và chứng thư.
\item Xác nhận môi trường deploy, lịch chuyển đổi, backup, RPO/RTO và quota dịch vụ từ bằng chứng vận hành thật.
\item Repository hiện không có bảng \texttt{task} hoặc module công việc. Xác nhận với giảng viên xem đây là yêu cầu bắt buộc; báo cáo không ghi chức năng này là đã cài đặt.
\item Thống nhất với giảng viên việc giao diện ADMIN có cần shell riêng; code hiện dùng shell chung, menu thay đổi theo role.
\end{itemize}

\section{Nguồn sơ đồ}
Các sơ đồ được lưu dưới dạng Mermaid trong \texttt{\detokenize{docs/report/diagrams/*.mmd}}. Nếu máy có Mermaid CLI, kết xuất từng sơ đồ sang PDF bằng lệnh mẫu:
\begin{verbatim}
mmdc -i docs/report/diagrams/01-chuc-nang.mmd `
  -o docs/report/diagrams/01-chuc-nang.pdf
\end{verbatim}
Sau khi kết xuất, biên dịch báo cáo lại hai lượt. Nếu không có Mermaid CLI, cài công cụ theo quy định máy nộp hoặc sử dụng công cụ Mermaid được trường chấp thuận; không thay sơ đồ bằng hình tự vẽ không đối chiếu source.
